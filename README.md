<summary><strong>G-HUB ERP - Enterprise Resource Planning Platform</strong></summary>

### G-HUB ERP

A modern enterprise resource planning platform focused on workforce management, organizational configuration, scheduling, holiday management, operational workflows, and internal business processes.

| Field | Details |
|---|---|
| Stack | Next.js 14, React 18, TypeScript, Tailwind CSS, NestJS, Prisma, PostgreSQL, Docker, Socket.IO, React Query |
| Scale | Full-stack monorepo with frontend, backend API, database schema, Docker infrastructure, seed workflows, and operational modules |
| Performance | Type-safe application structure, server/API separation, React Query data handling, indexed relational models, containerized local development |
| Security | JWT authentication, password hashing, role-based access, app-level permission guards, protected routes, admin user and permission management |
| Impact | Centralizes business operations across people, organization, time, holidays, bookings, members, lecture rooms, agents, and reporting workflows |
| Repository | [github.com/GoneSeeder/G-HUB-ERP](https://github.com/GoneSeeder/G-HUB-ERP) |

G-HUB ERP is the primary expression of my current engineering work: a business platform designed around real internal operations instead of generic CRUD screens. The system combines a modern React/Next.js frontend with a NestJS and Prisma backend, PostgreSQL data modeling, Docker-based development, authentication, role access, app permissions, and workflow-heavy modules for HR and information management.

The platform includes protected application areas for admin, hub, human source, and information workflows. It models users, roles, apps, user-role mappings, role app permissions, user app permissions, members, agents, bookings, name lists, lecture rooms, speakers, lecture sessions, lecture history, bonus cards, and reference data. It also includes holiday calendar work, leave settings planning, approval workflow design, Thai holiday ingestion, and operational interfaces for enterprise scheduling and workforce configuration.
